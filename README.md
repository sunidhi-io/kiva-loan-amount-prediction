# Kiva Loan Amount Prediction Using XGBoost

## Project Overview
This project uses machine learning to predict loan amounts using Kiva loan data. It includes data cleaning, exploratory data analysis, feature engineering, and model evaluation.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib and Seaborn
- Scikit-learn
- XGBoost
- Jupyter Notebook

## Project Workflow
1. Data cleaning and preprocessing
2. Exploratory Data Analysis (EDA)
3. Feature engineering and categorical encoding
4. Training an XGBoost regression model
5. Evaluating the model using MAE, RMSE, and R²

## Dataset
The project uses Kiva loan data. The dataset is not included in this repository; users must obtain it from an authorized source and update the file path before running the notebook.

## How to Run
1. Download or clone this repository.
2. Install the required Python libraries.
3. Open the notebook in Jupyter Notebook or Google Colab.
4. Update the dataset path to match your environment.
5. Run the notebook cells in order.

## Note
Model performance depends on the dataset and train/test split. See the notebook for the actual evaluation results.
